# やさいっこ冒険村

やさいっこたちが冒険者になって暮らす村を育てる、ドット絵の村づくりシミュレーションです。
ブラウザだけで動きます。スマホでの操作に合わせて作っています。

## 遊び方

- 空いているマスをタップすると、建物を建てられます。真ん中の道には建てられません。
- 建物を建てると、冒険者がやってきます。冒険者は自分で考えて、宿屋に泊まったり、道具屋や武器屋で買い物をしたり、食堂でごはんを食べたりして、上の門からダンジョンへ冒険に出かけます。
- お店の料金が村の収入になります。冒険者がダンジョンから持ち帰ったお宝の4分の1も、村の資金になります。
- 建物をとなり合わせに建てると「コンボ」が生まれて、料金や人気が上がります（全11種）。
- 人気が上がると冒険者が来やすくなり、村ランクが上がると新しい建物とダンジョンが解放されます。
- 家を建てると、気に入った冒険者が住民になって、村に住みつきます。
- 冒険者はレベルが上がると装備を買いそろえ、Lv10になると訓練所で転職します。
- ときどき魔物が村に攻めてきます。村にいる冒険者たちが迎え撃ちます。

## 中身

- 建物 14種、コンボ 11種、ダンジョン 5か所、職業 4種（転職先あり）、目標 16個
- BGM（昼・夜・魔物の襲撃）と効果音は、ブラウザの Web Audio で鳴らしています。音声ファイルは使っていません。

## セーブ

村のようすはブラウザの localStorage に保存されます。アプリを閉じていたあいだの売上も、戻ったときにもらえます（最大4時間分）。
