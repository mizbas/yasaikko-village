# やさいっこ冒険村

顔のついた野菜「やさいっこ」たちが冒険者になる世界で、冒険者が集まる村を育てる放置ゲームです。
斜め見下ろしのドット絵で、ブラウザだけで動きます。インストールは要りません。

## 遊び方

- **見わたす**：村をドラッグすると、まわりを見わたせます。
- **建てる**：空き地をタップすると「建設」が開きます。設備・お店・飲食・飾りのタブから選び、もう一度タップすると建ちます。
- **冒険者**：冒険者は自分で考えて動きます。宿屋や温泉で休み、道具屋でおくすりを、武器屋・防具屋・アクセサリー屋・魔法屋で装備を買い、食堂・屋台・パン屋でごはんを食べます。
- **フィールドで狩り**：準備ができた冒険者は門から外のフィールドへ出て、うろついている魔物とマップ上で戦います。たおすとお金・経験値・アイテムが手に入り、疲れたら村へ帰ってきます。
- **ダンジョン探検**：フィールドにある洞窟や塔の入口をタップすると、冒険者を最大4人まで呼んで探検隊を送り出せます。探検中のようすは画面下の帯で見られます。探検度が100%になるとボス戦です。メニューの「おまかせ探検」をオンにすると、冒険者たちが自分で探検に出かけます。
- **成果**：パーティが帰ってくると、持ち帰ったアイテム・ダイアポイント・村の収入が表示されます。
- **研究**：アクセサリー屋・パン屋・温泉・魔法屋・やさいっこ像は、ダンジョンのアイテムを使って研究すると建てられるようになります。
- **建物のレベル**：お客さんが来て「にぎわい」がたまると、建物は自動でレベルアップします。お金やダイアポイントを使ってレベルを上げることもできます。
- **コンボ（全16種）**：となり合わせに建てるとコンボが生まれます（例：宿屋＋食堂＝休息セット）。
- **人気と村ランク**：人気が上がると冒険者が来やすくなり、村ランクが上がると新しい建物やダンジョンが解放されます。
- **住民と転職**：家を建てると、気に入った冒険者が住みつきます。Lv10になると訓練所で上位の職業に転職します。
- **魔物の襲撃**：ときどき魔物が攻めてきて、村の冒険者たちが迎え撃ちます。
- **日付と季節**：1週ごとに時間が進み、季節によって木や地面の色が変わります。
- **メニュー**：建設、冒険者、ダンジョン、倉庫（アイテムを売れます）、目標、コンボ図鑑、スカウト（ダイア5）、できごと、BGM・効果音のオン/オフ。

アプリを閉じていたあいだの売上も、戻ったときにもらえます（最大4時間分）。

## 道

建設の「道」タブで、土の道・石だたみ・レンガ道をしけます。冒険者は道を通りたがり、道の上では早く歩きます。

## マップ

マップの最終ボスをたおすと、次のマップへ行けるようになります（メニュー →「マップ」）。

- **やさいっこ村**：野菜の冒険者。いもむし・もぐら・カラス・タヌキ・月うさぎ
- **くだもの島**：くだものの冒険者。カニ・カモメ・ヒトデ・タコ・サメ。ヤシの木・パラソル・灯台・ジュース屋
- **おかし王国**：おかしの冒険者。アリ・ハチ・チョコスライム・クッキー兵・わたあめドラゴン。キャンディの木・チョコ噴水・わたあめの塔・ケーキ屋

お金・ダイア・アイテムは持っていけます。冒険者と建物はそれぞれのマップに残ります。

## アプリとして使う（PWA）

GitHub Pages のURLをスマホで開き、ホーム画面に追加すると、アプリのように全画面で遊べます。

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「アプリをインストール」または「ホーム画面に追加」

一度開けば、オフラインでも遊べます。ネットにつながっているときは毎回最新版を読み込むので、更新もすぐ反映されます。開いている間に新しい版が出ると「新しいバージョンがあります。タップで更新」と表示されます。

※ iPhoneでは、ホーム画面のアプリと Safari で開いたページのセーブデータは別々になります。

## 音

BGMと効果音は Web Audio で鳴らしています。音声ファイルは使っていません。

## 動かし方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages で公開する場合は、Settings → Pages で `main` ブランチのルートを選んでください。

## セーブ

進み具合は、ブラウザの localStorage に保存されます。

## そらかけランナー（おまけ）

横向きで遊ぶランナーゲームです。`runner/` フォルダに入っています。
タップでジャンプ、もう一度タップで2段ジャンプ。コインを集めてキャラ・神獣・ペットを手に入れましょう。
